# Phronon

Phronon is an accessibility-first open-source study assistant for blind and low-vision students.

## Mission
Help blind students study independently by importing notes and documents, extracting text, reading them aloud, and later explaining or summarizing them using free local tools.

## Version 1 goals
- Import TXT, PDF, and image files
- Extract readable text
- Read text aloud
- Support keyboard-first navigation
- Save reading position
- Prioritize English and Arabic

## Principles
- Accessibility first
- Local-first where possible
- No paid APIs
- Simple and stable over flashy
